# Mon Trajet en Portugais (Portugal) — « PortP »

App iOS (Capacitor) 100 % audio pour apprendre le portugais du Portugal (portugais européen) en conduisant, en courant ou en marchant. Dupliquée depuis « Mon Trajet en Portugais (Brésil) » (PortB).

- Nom App Store : `Portugais Européen Mon Trajet`
- Bundle ID : `com.tonstudio.montrajet.portp`
- RevenueCat : projet `Mon Trajet PortP`, produit `version_complete_portp`, entitlement `mon_trajet_portp_pro`
- Codemagic : profil de provisionnement `mon_trajet_portp_app_store` + certificat partagé `iOS Distribution`
- Synthèse vocale : `pt-PT` (champ `pt` dans data.js)
